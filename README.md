### Selected work

**[MCP-Dedup](https://github.com/EduBCarv/MCP-Dedup)**

An experimental benchmark investigating duplicate side effects in stateless MCP deployments.

Explores retries, response failures, load balancing, and the challenges of maintaining consistency across replicas.

`Python` · `Docker` · `PostgreSQL` · `Nginx`

**[Aurel](https://github.com/EduBCarv/Aurel)**

A native macOS menu bar application for controlling audio independently for each app.

Per-app volume, mute, audio routing, and amplification in a minimal interface.

`Swift` · `macOS` · `Xcode`
